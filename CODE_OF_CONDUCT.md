# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## The short version

- Be respectful and patient. Many people here are new to code — that's the point. Nobody gets
  talked down to for asking how to open a terminal.
- No harassment, insults, discrimination, sexualised content or personal attacks.
- **Respect privacy.** Never post someone else's health data or personal details, and never
  pressure anyone to share theirs.
- Disagree about the code and the data, not the person.

## Enforcement

Report problems privately to the maintainers using GitHub's private reporting
(**Security → Report a vulnerability**, mark it "Code of Conduct") or by contacting the
[Bluecollarlabs](https://github.com/Bluecollarlabs) organization owners. Reports are kept
confidential. Maintainers may edit or remove content and warn, suspend or ban participants,
following the Contributor Covenant 2.1 enforcement guidelines.
